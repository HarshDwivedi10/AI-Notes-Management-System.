## System Prerequisites

Before running the application, ensure the following software is installed on your machine:

1. PHP: Version 8.2 or higher (PHP 8.3 recommended) with standard extensions (pdo_sqlite, json, mbstring, openssl, tokenizer, xml).
   - Check version: php -v
2. Composer: Version 2.0 or higher.
   - Check version: composer -V
3. Web Browser: Any modern web browser (Google Chrome, Microsoft Edge, Mozilla Firefox, Apple Safari).
4. Terminal / Shell: Command Prompt / PowerShell (Windows) or Terminal (macOS / Linux).

## Step-by-Step Setup & Execution

Follow these step-by-step instructions to get the application up and running locally in under 2 minutes.

---

### Step 1: Clone Repository & Open Directory

Open your terminal or command prompt and run:

git clone https://github.com/HarshDwivedi10/AI-Notes-Management-System.git
cd AI-Notes-Management-System

---

### Step 2: Install PHP Dependencies

Install all required Composer packages:

composer install

---

### Step 3: Environment Setup

Copy the example environment configuration file to create your active .env file:

Windows (PowerShell / Command Prompt):
copy .env.example .env

macOS / Linux:
cp .env.example .env

Next, generate the application encryption key:

php artisan key:generate

---

### Step 4: Database Setup & Seeding

The repository comes pre-configured with SQLite for zero-setup evaluator convenience. No local MySQL server or database credentials are required.

Run the database migrations and seed pre-populated demo notes:

php artisan migrate --seed

Note: If you ever wish to completely reset the database back to clean seeded state during evaluation, simply run:
php artisan migrate:fresh --seed

---

### Step 5: Start the Development Server

Launch the built-in Laravel development server:

php artisan serve

You will see output confirming the server has started:

  INFO  Server running on [http://127.0.0.1:8000].  
  Press Ctrl+C to stop the server

---

### Step 6: Access the Application in Your Browser

Once the server is running, open your web browser and navigate to:

- Executive SPA Dashboard: http://localhost:8000
- Interactive Swagger API Documentation: http://localhost:8000/docs
- Raw OpenAPI 3.0 JSON Spec: http://localhost:8000/swagger.json

## Optional Live AI API Setup

The application works 100% offline out-of-the-box using embedded deterministic term-frequency vectorizers (TF-IDF) and NLP sentence-scoring summarization algorithms.

If you wish to test live API calls with OpenAI or Google Gemini during evaluation:

1. Open the .env file in your root project directory.
2. Provide your API key for either OpenAI or Gemini:

OPENAI_API_KEY=your_actual_openai_api_key_here
OPENAI_EMBEDDING_MODEL=text-embedding-3-small
OPENAI_COMPLETION_MODEL=gpt-4o-mini

OR Google Gemini Configuration:
GEMINI_API_KEY=your_actual_gemini_api_key_here

3. Clear application config cache:
php artisan config:clear

The system will automatically detect the API keys and use OpenAI / Gemini for vector generation and note summaries. If an API request fails or times out, the system gracefully falls back to the local algorithms without interrupting the user experience.

## Troubleshooting & FAQs

Q1: "Port 8000 is already in use"
If port 8000 is currently used by another process on your machine, specify a custom port when starting php artisan serve:
php artisan serve --port=8080
Then open http://localhost:8080 in your browser.

Q2: "Database file does not exist"
If SQLite raises an error about missing database.sqlite, create the file manually:
Windows (PowerShell):
New-Item -ItemType File -Path database\database.sqlite -Force
macOS / Linux:
touch database/database.sqlite
Then run php artisan migrate --seed.

Q3: How to view API endpoints directly in Swagger UI?
Visit http://localhost:8000/docs. The embedded Swagger UI allows you to test endpoints interactively (Try it out button) directly from your browser.
